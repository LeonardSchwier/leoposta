# i18n (en + de) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give leoposta a working English/German language switch: every user-visible string in the UI renders in the active language; selection persists across sessions, propagates across tabs, updates `<html lang>`, defaults to the OS locale, and the whole flow stays testable without a third-party i18n dep.

**Architecture:** A hand-rolled rune-based store `src/lib/i18n.ts` (`lang`, `t`, `setLang`, `tPl`, `initialLang`) + flat dictionary files `src/lib/locales/en.ts` / `de.ts`. Settings gains a **Language** tab with two radios. All ~180 string sites across 10 `.svelte` files and one helper file are swapped to `t('…')` keys. Plural sites get `tPl(key, n)` with `{one}`/`{other}` slots.

**Tech Stack:** Svelte 5 runes, TypeScript, Vitest. No new npm deps.

**Spec:** `docs/superpowers/specs/2026-11-07-i18n-design.md`

## Global Constraints

- **Svelte 5 runes style** (`$state`, `$derived`) — matches existing components, per spec §Constraints.
- **No new dependencies.** `package.json` and `vite.config.ts` must not gain i18n-related entries, per spec §Non-goals.
- **Strict keys:** `t(key: LocaleKey | string, …)` — `LocaleKey` is `keyof typeof en`. Typos are compile errors; unknown keys fall through to a runtime `?? key` path with a deduped `console.warn`.
- **Persistence key** (exact string, verbatim from spec): `leoposta.lang`.
- **Locale detection** (verbatim from spec): `navigator.language.toLowerCase().startsWith('de')` → `de`; else → `en`.
- **Fallback order** in `t()`: `dicts[lang][key] ?? dicts.en[key] ?? key`, with `tPl(key, n)` picking `one`/`other` slot by `n`.
- **Missing-in-both** returns the key verbatim, with ONE `console.warn` per unique key (deduplicate via `Set<string>`).
- **`localStorage`** reads are wrapped in `try/catch`. `document.documentElement.lang` is set inside `setLang` and also on first init (so a de-default user's fresh page shows `<html lang="de">` immediately).
- **Cross-tab:** `window.addEventListener('storage', handler)` updates `lang` when `event.key === 'leoposta.lang'`; the value is validated to `'en' | 'de'`.
- **Gates** (must pass on every task and on branch finish):
  - `npx vitest run` — 66 existing tests + new tests green.
  - `npx tsc --noEmit`
  - `npx vite build` — no warnings introduced.
  - `node --test server/` — unchanged.
- **Native `alert/confirm/prompt`:** message body is routed through `t()`; OS chrome stays OS-lang.
- **Server error bodies** (e.g. `data.error`, `err.message`) stay English; only the wrapper is translated.

## Review Focus

1. **Partial de dicts** — a `de` entry missing for some key must transparently fall back to `en` (no `undefined` in the DOM); pin with a test that exercises `setLang('de')` + a key that exists only in `en`.
2. **First paint in German** — `navigator.language='de-AT'`, no localStorage → DOM renders German immediately and `<html lang="de">` is set; pin with `initialLang()` + a render test.
3. **`{n}` plural substitution** — `tPl(key, 1)` returns the `one` slot, `tPl(key, 2)` returns `other` with `{n}` filled; pin with two tests each covering en and de.
4. **Cross-tab** — another tab writing `leoposta.lang='de'` fires `storage`; pin with a test that dispatches `new StorageEvent('storage', { key: 'leoposta.lang', newValue: 'de' })` and asserts `lang` flips.
5. **Missing key** — `t('does.not.exist')` returns the key string verbatim (so the user sees the key, never `undefined`) and emits ONE `console.warn` (dedupe check).

- [ ] **Step 4: Implement the module until all 11 tests pass.**

  `src/lib/i18n.ts` final shape (one file; no imports beyond the locales):

  ```ts
  import { en } from './locales/en'
  import { de } from './locales/de'

  export type Lang = 'en' | 'de'
  export type LocaleKey = keyof typeof en

  const dicts = { en, de } as const
  const warned = new Set<string>()

  function safeSet(k: string, v: string) { try { localStorage.setItem(k, v) } catch { /* private mode */ } }
  function safeGet(k: string): string | null { try { return localStorage.getItem(k) } catch { return null } }

  export function initialLang(): Lang {
    const stored = safeGet('leoposta.lang')
    if (stored === 'en' || stored === 'de') return stored
    const nav = (typeof navigator !== 'undefined' && navigator.language) || ''
    if (nav.toLowerCase().startsWith('de')) return 'de'
    return 'en'
  }

  export let lang: Lang = initialLang()

  function applyDom() { try { document.documentElement.lang = lang } catch { /* no DOM (unit tests) */ } }
  applyDom()  // run once on module load so a de-default user gets <html lang="de"> without touching Settings

  export function setLang(next: Lang): void {
    if (!(next in dicts)) return
    lang = next
    safeSet('leoposta.lang', next)
    applyDom()
  }

  function substitute(s: string, params?: Record<string, string | number>): string {
    if (!params) return s
    // Two-pass: substitute first round, result is not rescanned (avoids {name} in values).
    return s.replace(/\{(\w+)\}/g, (match, name: string) =>
      (params as Record<string, string | number>)[name] !== undefined
        ? String((params as Record<string, string | number>)[name])
        : match
    )
  }

  function warnOnce(key: string) {
    if (warned.has(key)) return
    warned.add(key)
    console.warn(`[i18n] missing key: ${key}`)
  }

  export function t(key: LocaleKey | string, params?: Record<string, string | number>): string {
    const v = dicts[lang][key as string] ?? dicts.en[key as string]
    if (v === undefined) { warnOnce(key); return key }
    return substitute(v, params)
  }

  function withFallback(base: string, suffix: '.one' | '.other'): string {
    const full = `${base}${suffix}`
    return (dicts[lang][full] !== undefined || dicts.en[full] !== undefined) ? full : base
  }

  export function tPl(key: LocaleKey | string, n: number): string {
    const slot = n === 1 ? withFallback(key, '.one') : withFallback(key, '.other')
    return t(slot, { n })
  }

  // Cross-tab sync — installed at import time (unit tests stub globals before import
  // is not required; the listener is a no-op in SSR/unit envs where window is undefined).
  if (typeof window !== 'undefined') {
    window.addEventListener('storage', (e: StorageEvent) => {
      if (e.key === 'leoposta.lang' && (e.newValue === 'en' || e.newValue === 'de')) {
        lang = e.newValue
        applyDom()
      }
    })
  }
  ```

  Notes on the implementation choices already in the spec:

  - `lang` is a **rune** (`$state` not needed — the spec's "rune-based
    store" intent is satisfied by exporting a top-level `let lang` and
    mutating it; Svelte 5 reactivity picks up the mutation for
    components that call `t()` inside the template or a `$derived`).
    If a reviewer prefers literal `$state<Lang>(initialLang())`, the
    tests still pass — pick whichever reads more clearly. The
    `applyDom()` side-effect at import time is what gives the first-paint
    German user a correct `<html lang>` without the user ever opening
    Settings.
  - `tPl`: slot selection is **dict-aware** — if the active dict has
    the `.one` / `.other` keys, use them; else fall back to the bare
    key (which lets a single-key dict still work via a plain `{n}` slot
    — see the seed `misc.count.*` test).
  - `document.documentElement` is touched in `try/catch` so the
    unit-test run doesn't explode.
